Deloitte Daikibo Manufacturing Intelligence – Power BI Project

Project Overview

This is an independent Power BI project developed using the Daikibo manufacturing telemetry dataset. It extends the analysis performed during the Deloitte Data Analytics Job Simulation by creating an interactive business intelligence dashboard.

The project focuses on manufacturing performance, machine downtime, operational efficiency, and workforce equality.

Dashboard Pages

1. Executive Overview

* Total Downtime
* Unhealthy Events
* Total Factories
* Total Device Types
* Factory-wise Downtime Analysis
* Device Type Downtime Analysis
* Machine Health Distribution

2. Factory Intelligence

* Factory and Section-wise Downtime
* Machine Performance by Device Type
* Machine Health Distribution
* Interactive Factory and Section Filters

3. Workforce Equality

* Total Records
* Average Equality Score
* Highly Discriminative Records
* Equality Class Distribution
* Average Equality Score by Job Role
* Factory-wise Equality Analysis
